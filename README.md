# AI 与电商数据采集

一个自己架在服务器/NAS 上的小网站，帮你把三类信息收拢到一处看：

1. **AI软件技术追新**：GitHub 上 AI 相关的热门开源项目（大模型应用框架、AI 绘画视频、AI 语音数字人、AI 智能体、AI 知识库与搜索），每个分类按星数取前 15 名
2. **电商工具软件**：GitHub 上的电商 ERP、电商图片/视频制作工具、直播带货与选品工具，同样按星数取前 15 名
3. **电商资讯**：中文科技/电商媒体的新闻订阅（平台规则变化、电商行业新闻），加上**海外AI电商资讯**——英文科技媒体（TechCrunch AI、MIT 科技评论、Ars Technica AI）的新闻会自动翻译成中文，前台双语展示（中文在上、英文原文小字在下）

网站分前台和后台，都要账号密码登录才能进。**登录成功后一律先到前台首页**，管理员从左侧边栏或右上角的"管理后台"按钮进后台。

## 部署三步走

**第 1 步：装 Docker**
电脑或 NAS 上装好 Docker 和 Docker Compose（群晖/飞牛 NAS 自带套件中心可装）。

**第 2 步：配账号密码**
```bash
cd ai-ecommerce-collector
cp .env.example .env
```
用记事本打开 `.env`，把 `ADMIN_PASSWORD` 改成你自己的密码（`ADMIN_USER` 是管理员账号名，一般不用改）。想让 GitHub 采集更快更稳，可以去 https://github.com/settings/tokens 申请一个令牌填到 `GITHUB_TOKEN`（不填也能用）。

**第 3 步：启动**
```bash
docker compose up -d
```
然后浏览器打开 `http://你的服务器IP:8080`，用刚才设的账号密码登录。

## 平时怎么用

- **看数据**：登录后先到首页——顶部是欢迎横幅（今天日期、今日更新了多少条），下面是 3 大模块的统计卡片，再下面是全站最新 12 条。点进模块看每个小分类的前 5 条，再点进小分类看完整列表。标题点一下就在新窗口打开原链接。
- **搜内容**：右上角搜索框输入关键词，可以搜标题和简介（英文资讯的中文译文也能搜到）。
- **手动录入**：进管理后台（左侧边栏"管理后台"），"条目管理" → "添加一条"，填标题、链接、一句话说明、来源名称，选好分类保存——可以给任意子分类加条目。
- **立即采集**：后台"数据总览"点"立即采集一次"，不用等到凌晨。
- **加浏览账号**：后台"账号管理"可以给看数据的人开账号（不用给管理员权限）。普通账号登录后看不到"管理后台"入口。
- **改密码**：后台"改密码"。
- **看采集记录**：后台"采集日志"，每一次自动/手动采集的结果都在这里。

## 英文资讯双语说明

"海外AI电商资讯"分类抓的是英文媒体的新闻。采集时会自动把英文标题和英文摘要翻译成中文存下来，前台显示中文标题（下面小字附英文原标题）、中文简介（下面小字附英文原文）。翻译失败也不影响入库，只是那条暂时只显示英文。

## 翻译配置方法

英文翻译默认走 MyMemory 免费接口，不用注册、开箱即用。如果想让免费额度更大，在 `.env` 里加一行 `MYMEMORY_EMAIL=你的邮箱`。

如果想要更好的翻译质量，可以复用你的 DeepSeek 密钥（和玄盘那个一样），在 `.env` 里加三行：
```
TRANSLATE_BASE_URL=https://api.deepseek.com/v1
TRANSLATE_MODEL=deepseek-chat
TRANSLATE_API_KEY=你的DeepSeek密钥
```
配好重启容器后生效。配了之后，英文资讯走 DeepSeek 翻译，同时 GitHub 项目的英文简介也会被翻译成中文（GitHub 仓库名不翻译）。不配的话，GitHub 项目简介就不翻译、只显示英文原文。

## 数据多久更新一次

每天凌晨 3 点自动全量采集一次（GitHub 项目 + 新闻订阅，含英文资讯翻译）。人工录入的条目是你自己加的，不会自动变。

## 常见问题

- **GitHub 采集条数不够 15 条？** 有些小众关键词本来就没那么多项目，有几条是几条；没填 GITHUB_TOKEN 时每小时限 60 次查询，填了令牌更稳。
- **英文资讯没翻成中文？** 翻译接口偶尔会超时失败，采集日志里能看到；下一次采集会自动重试。也可以配上 DeepSeek 翻译更稳。
- **数据存在哪？** 存在项目目录下的 `data/app.db` 文件里，容器删了重建数据还在。备份就拷这个文件。
- **忘了管理员密码？** 停掉容器，删掉 `data/app.db`，重新 `docker compose up -d`，会用 `.env` 里的密码重建（注意：旧数据会清空，先备份）。
- **换端口？** 改 `docker-compose.yml` 里 `"8080:8080"` 前面的数字，比如 `"9000:8080"` 就是用 9000 端口访问。
