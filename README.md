# AI 与电商数据采集

一个自己架在服务器/NAS 上的小网站，帮你把三类信息收拢到一处看：

1. **AI 软件技术追新**：GitHub 上 AI 相关的热门开源项目（大模型框架、AI 绘画视频、AI 语音数字人、AI 智能体、AI 知识库），每个分类按星数取前 15 名
2. **电商工具软件**：GitHub 上的电商 ERP、电商图片/视频制作工具，同样按星数取前 15 名
3. **电商资讯**：中文科技/电商媒体的新闻订阅，每天自动抓
4. **平台销售排行**（淘宝天猫、京东、拼多多、抖音电商、亚马逊）：这些平台没有公开免费的数据接口，所以做成**人工录入**——你在后台一条条加上去，前台展示
5. **达人与带货**：达人榜单、带货趋势方向也是**人工录入**；直播带货选品工具从 GitHub 自动采集

网站分前台和后台，都要账号密码登录才能进。

## 部署三步走

**第 1 步：装 Docker**
电脑或 NAS 上装好 Docker 和 Docker Compose（群晖/飞牛 NAS 自带套件中心可装）。

**第 2 步：配账号密码**
```bash
cd ai-ecommerce-collector
cp .env.example .env
```
用记事本打开 `.env`，把 `ADMIN_PASSWORD` 改成你自己的密码（`ADMIN_USER` 是管理员账号名，一般不用改）。想让 GitHub 采集更快更稳，可以去 https://github.com/settings/tokens 申请一个令牌填到 `GITHUB_TOKEN`（不填也能用）。

**第 3 步：启动**
```bash
docker compose up -d
```
然后浏览器打开 `http://你的服务器IP:8080`，用刚才设的账号密码登录。

## 平时怎么用

- **看数据**：登录后首页有 5 大模块，点进小分类看条目。标题点一下就在新窗口打开原链接。
- **手动录入**：进 `/admin`（右上角"管理后台"），"条目管理" → "添加一条"，填标题、链接、一句话说明、来源名称，选好分类保存。
- **立即采集**：后台首页点"立即采集一次"，不用等到凌晨。
- **加浏览账号**：后台"账号管理"可以给看数据的人开账号（不用给管理员权限）。
- **改密码**：后台"改我的密码"。

## 数据多久更新一次

每天凌晨 3 点自动全量采集一次（GitHub 项目 + 新闻订阅）。人工录入的条目是你自己加的，不会自动变。

## 哪些是手动录入的

平台销售排行的 5 个分类（淘宝天猫、京东、拼多多、抖音电商、亚马逊）、达人榜单数据、带货趋势方向——共 8 个分类。因为这些平台不开放免费数据接口，只能人工整理录入。

## 常见问题

- **GitHub 采集条数不够 15 条？** 有些小众关键词本来就没那么多项目，有几条是几条；没填 GITHUB_TOKEN 时每小时限 60 次查询，9 个分类刚好够用，填了令牌更稳。
- **数据存在哪？** 存在项目目录下的 `data/app.db` 文件里，容器删了重建数据还在。备份就拷这个文件。
- **忘了管理员密码？** 停掉容器，删掉 `data/app.db`，重新 `docker compose up -d`，会用 `.env` 里的密码重建（注意：旧数据会清空，先备份）。
- **换端口？** 改 `docker-compose.yml` 里 `"8080:8080"` 前面的数字，比如 `"9000:8080"` 就是用 9000 端口访问。
